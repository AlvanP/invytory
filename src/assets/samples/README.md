# Sample photographs

Drop JPG, PNG or WebP files here. No code changes. They appear in every sample invitation,
phone mockup and template preview on the website. A missing file just uses the drawn picture.

File names (lower case):

| File | Used for |
| --- | --- |
| `<kind>-hero.jpg` | The cover photo. kind = wedding, child-dedication, birthday, corporate, funeral |
| `<kind>-gallery-1.jpg` to `-4.jpg` | The four photos in the gallery |
| `<family>-hero.jpg`, `<family>-gallery-1.jpg` ... | Optional: for weddings only, family = white, igbo, yoruba, hausa |
| `<template-id>-hero.jpg`, `<template-id>-gallery-1.jpg` ... | Optional: one design only, e.g. `classic-elegance-hero.jpg` |

The most specific file wins: design, then family, then kind.
