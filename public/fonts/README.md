# Fonts you add yourself

## Restonasi (the "and" between the couple's names)

Restonasi is a script font by Storytype Studio. It is free for personal use only, so you need a
commercial licence before using it on a business website.

1. Buy / download it from the designer with a commercial licence.
2. Put the font file in THIS folder and name it exactly one of:
   - `Restonasi.woff2` (best), or
   - `Restonasi.otf`, or
   - `Restonasi.ttf`
3. Push to GitHub as usual. The invitations pick it up on their own, no code change.

Until the file is here, a free lookalike script (Pinyon Script) is shown instead.
